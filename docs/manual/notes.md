# 笔记与复习

将摘录、自己的理解和有用的回答留在笔记里，并保留回到原文的路径。

## 新建笔记 <!-- create -->

- 在右侧「笔记」点击「新笔记」，自行编写标题和正文。
- 选中文字或框选图表后，点击「记笔记」，保留选区来源。
- 在回答下方点击「存为笔记」，保存回答及其来源。

正文支持 Markdown。使用「预览」查看标题、列表、公式等排版，切回编辑后继续修改。

## 确认保存状态 <!-- save -->

笔记会在停止输入后自动保存。顶部状态显示是否正在保存或已经保存。

保存失败时，草稿会留在当前浏览器，先处理错误，再点击「重试保存」。若出现版本冲突，可载入最新版本，或将自己的草稿另存副本；不要直接覆盖还需要的修改。

浏览器中的草稿只保存在当前设备和浏览器，不能替代数据备份。

## 返回原文 <!-- source -->

点击笔记底部的来源，回到对应课件与页码。有选区的笔记还会定位原来的文字或图表。阅读页上的笔记标记也可以打开对应记录。

![笔记底部保留课件名称、页码和来源入口。](/manual/notes.jpg)

普通手动笔记可能只属于课件或课程，没有具体选区。显示「来源已删除」时，笔记仍可阅读，原页无法跳转；已经保存的框选图片仍可查看。

## 查找与复习 <!-- find -->

在笔记搜索框输入标题或正文中的关键词。课程中可以切换「本章笔记」和「全课程笔记」。

复习时可先读自己的概括，再打开来源核对。需要重新理解时，回到原页继续提问，或在「研究」中设定复习目标。

## 恢复内容 <!-- restore -->

在笔记的版本记录中查看旧内容，选择「恢复此版本」。如有尚未保存的修改，先完成保存再恢复。

删除后可点击「撤销」，也可通过笔记更多操作进入「已删除笔记」，打开记录后点击「恢复」。

需要整理跨章节的材料时，继续阅读[总览与章节整理](#/manual/overview)。
