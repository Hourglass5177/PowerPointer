# 连接与设置

阅读和自行记录笔记可直接使用。AI 解释、问答、章节整理和研究需要可用的模型连接。

## 连接模型服务 <!-- connect -->

在左侧「设置」打开 AI 设置，进入「模型连接」。

**使用 ChatGPT / Codex**：应用读取本机 Codex 登录状态。未连接时点击「通过官方页面登录」，完成后返回检查。连接信息中可以查看服务提供的额度；额度未返回时会显示不可用。

**使用 API 服务**：点击「添加连接」，选择服务预设，填写服务地址与 API 密钥。地址填写到 API 根路径，再确认协议。点击「保存并获取模型」读取目录，必要时填写自定义模型 ID。确定默认模型后，可以「测试默认模型」。测试会实际调用服务。

**使用本地模型**：选择相应预设或兼容协议，填写本地服务地址；服务不要求密钥时可以留空。使用前需自行启动模型服务。

保存连接后，可将它设为默认连接。API 凭据由当前 Windows 用户加密保存；不要把密钥写进问题或笔记。

## 选择模型与能力 <!-- models -->

问答和研究中的模型选择器支持搜索、收藏及最近使用。显示名称可自定义，但模型 ID 必须与服务提供的名称一致。

模型目录未必提供图像、工具调用或推理能力。标为「待确认」时，根据服务实际能力设置，不要仅凭模型名称判断。

- 阅读扫描页、公式和图表，需要支持图像的模型。
- 仅使用可提取文字时，开启「仅文本」；这不会自动识别扫描图片。
- 资料工具需要模型支持工具调用；思考强度只显示已配置的可用选项。

切换模型不会删除已有对话，但不同服务可用的能力可能不同。

## 保存常用配置与助手 <!-- profiles -->

「常用配置」保存模型和参数组合，问答或研究时可以直接选用。

「助手」用于保存工作方法、表达风格、默认模型、资料范围和可用工具。可以选用现有助手，也可以新建并填写自己的要求。

选择助手或常用配置后，发送前仍应检查当前范围和联网状态。

## 管理学习背景 <!-- memory -->

「学习背景」中可以保存学习偏好、课程术语或研究目标，并随时修改、删除。这些明确保存的内容可能进入后续任务的背景。

学习背景适合记录长期需要的约定；临时问题放在当前对话，详细理解保存在笔记。

## 联网与工具扩展 <!-- tools -->

在「工具扩展」配置搜索服务或只读 HTTP MCP。Codex 可使用订阅提供的搜索；API 模型可通过配置的 Brave Search 查找公开资料。每次任务仍需要开启联网。

MCP 连接需要填写可信的 HTTP 地址，获取工具后勾选可用工具，并授权给相应助手。只有满足只读声明及启用、授权条件的工具可用。

联网会将相关搜索词发送给搜索服务；外部工具会收到调用参数。不需要外部资料时，保持联网关闭即可。

## 用量与环境 <!-- usage -->

「用量」显示服务实际返回的 Token、耗时和状态；未返回的数据会标为「未提供」，不据此估算费用。

「帮助 → 连接与环境检查」可检查连接与运行环境。PPT 无法转换、模型列表为空时，先查看对应错误，再按[常见问题](#/manual/help)处理。
