# 历史与会话

「历史」保存过去的问答。通过搜索和筛选找回讨论，也可以从旧问题继续追问或另开分支。

## 新建与继续 <!-- continue -->

对话顶部的加号用于新建会话。课程内切换章节会保留当前正式会话；独立课件使用各自的会话。

进入「历史」，按课程、课件筛选，或搜索标题与消息内容。点击「继续」回到对应对话。输入草稿按课件和会话保存在当前浏览器中。

## 整理会话 <!-- organize -->

会话可以重命名、置顶或归档。归档适合暂时结束的讨论，之后可以「恢复并继续」。

删除会话前会提示影响范围。其他分支和已打开的解释窗按提示保留；删除不等于归档，谨慎处理仍需回看的记录。

## 修改问题与重新回答 <!-- branches -->

「修改问题」和「重新回答」都会创建分支，保留原会话，方便比较不同提问或不同模型的结果。

修改问题沿用原问题的页面和选区，并可调整模型设置。重新回答使用输入框当前的 AI 设置；错误后的重试则沿用原设置和资料。

如果提示无法可靠恢复或切分模型会话，先查看错误信息。不要假定修改已经成功，也不要连续重复发送。

## 导出记录 <!-- export -->

在对话顶部更多操作或历史记录中选择导出，获得 Markdown 文件。导出包含问答、课件名、页码和引用说明。

导出的 Markdown 不打包页面截图。需要保留完整资料与附件时，请同时[备份应用数据](#/manual/help/backup)。

## 来源变化后查阅 <!-- missing -->

课件被移除或删除后，保留的问答仍可查找。显示「来源已删除」的记录无法跳回原页；历史中保存的资料范围也不会自动替换成新文件。

要基于新版本课件继续学习，请打开新的资料，检查来源后再提问。
