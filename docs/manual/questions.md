# 提问与理解

围绕原文提出问题，选择足够的背景，再通过来源核对回答。局部难点适合解释窗，持续讨论适合右侧对话。

## 解释选区 <!-- explain -->

选中文字或框选图表后，点击「弹窗解释」。解释窗保留创建时的页码、选区和背景，之后翻页不会改变它正在讨论的内容。

可以在窗内追问，也可以继续选取回答中的文字打开子解释窗。顶部路径用于返回上层；暂时不用的窗口可以最小化，稍后恢复。

需要保留回答时，点击「存为笔记」；需要放入正式会话时，点击「保存为正式对话」。

## 在对话中提问 <!-- chat -->

右侧「对话」可以直接输入问题。选区引用会显示在输入区附近，发送前检查是否仍然需要。Enter 发送，Shift + Enter 换行。

问题尽量写清想解决的困难，例如：“为什么这里需要连续性条件？去掉后会发生什么？”

生成时可以停止，也能继续写下一条问题。向上查看历史时，回答不会强行把页面滚回底部；需要时点击「回到最新」。

## 选择问答范围 <!-- scope -->

输入区显示本次问题的页码。通过底部「资料范围」，或「设置」中的「范围」选择：

| 范围 | 适合的情况 |
| --- | --- |
| 当前页 | 解释本页定义、公式或图表 |
| 附近页 | 需要前后推导或相邻页面的背景 |
| 整份课件检索 / 课程来源 | 在课件或课程已选来源中寻找相关内容 |

附近页会补充前后各两页的文字；全文检索会寻找相关摘录，并不等于把所有页面图像都发给模型。其他页的视觉细节可通过搜索结果附图补充。

![发送前检查页码、资料范围和模型设置。](/manual/scope.jpg)

范围控制本轮新增资料，已有会话历史仍可能参与回答。需要从新的背景开始时，请新建会话。

## 查看模型实际收到的内容 <!-- evidence -->

问题中的「已发送材料」可查看页面图像、摘录和其他背景。回答中的引用及「来源」用于回到原页核对；悬停或键盘聚焦引用可查看预览。

AI 的解释与原文并不总是一致。检查结论时，尤其留意适用条件、单位、符号和被省略的步骤。来源已删除时，旧记录仍在，但无法打开对应页面。

## 调整回答方式 <!-- options -->

输入区可选择助手和模型；「设置」用于调整思考强度、回答长度、资料工具和联网能力。可用选项取决于模型；较长回答并不代表推理一定更准确。「问答字号」可在小、标准、大、特大之间切换，同时作用于问答区和解释窗，保存在当前浏览器，不影响课件和其他界面。

只有文字能力的模型，应启用「仅文本」模式；扫描页、图表和公式细节需要支持图像的模型。[连接与设置](#/manual/settings/models)介绍如何确认能力。

回答下方的快捷追问只会填入草稿，发送后才调用模型。修改问题和重新回答会创建分支，详见[历史与会话](#/manual/history/branches)。
