# 研究与成果

需要比较章节、核查推导、整理报告或生成练习时，在「研究」中给出目标，并把结果保存为可继续修改的成果。

## 开始研究 <!-- start -->

1. 打开课件或选择课程，进入「研究」，点击「新研究」。
2. 写清目标、关注点和期望结果，例如：“比较两章对连续性的要求，列出适用条件和反例，整理成对照表。”
3. 选择助手、模型和资料范围，在「资料、工具与高级参数」中确认课件勾选、图像和联网设置。
4. 点击「开始研究」。

研究使用启动时保存的资料与选区。随后在其他页面切换课件，不会悄悄更换当前任务的依据。

## 查看过程与继续 <!-- progress -->

任务列表显示进度。打开任务可查看过程、工具记录、回答和来源。切回阅读后，后台任务仍会继续。

需要结束当前生成时点击「停止」。达到运行上限时会保存进度；当前每次最多 20 轮或 15 分钟。之后可按任务提供的操作恢复，或填写补充要求后「继续研究」。

「结果待确认」表示结果尚不能确定。先查看记录和任务提示，避免重复启动造成重复调用。

## 比较或核查回答 <!-- compare -->

「双模型对比」让两侧使用相同资料和选区独立回答；先选择模型 A 和模型 B，再点击「开始对比」。对比不会让两侧额外联网或读取不同来源。

已有回答下方的「请另一模型核查」可以启动核查任务。查看依据后，可「采用此回答，继续讨论」，将选中的回答转入对话。

两份回答一致并不保证正确，仍需核对引用和推导条件。

## 编辑成果 <!-- edit -->

在研究工作区切换「成果」，打开报告、对照表、复习提纲或题目集。点击「编辑成果」修改标题和 Markdown 正文，使用「预览」检查排版。

成果修改需要点击「保存修改」，保存后形成新版本。浏览器会保留编辑草稿，但草稿不等于已保存版本。

需要模型继续处理时，点击「让 AI 继续修改」，回到任务中补充要求并发送。导出时选择「导出 Markdown」。

## 版本与恢复 <!-- versions -->

在「版本记录」中查看历史内容，选择「恢复此版本」可以生成恢复后的版本，原记录仍会保留。

遇到版本冲突时，可「载入最新版本」或「草稿另存副本」。删除成果会移入回收站，在成果列表勾选「查看回收站」后可以恢复。
