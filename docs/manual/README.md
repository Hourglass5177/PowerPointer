## 维护方式

- 每章首行是标题，首段是简介；二级标题末尾的 HTML 注释指定稳定小节 ID，修改文字时保留 ID。
- 站内链接采用 `#/manual/文章ID/小节ID`，文章 ID 与文件名一致。
- 配图放在 `public/manual/`，正文用 `/manual/文件名.jpg` 引用；尺寸记录在手册页面组件中，防止图片加载时正文跳动。
- 新增章节时更新 `shared/manual.ts` 中的目录与搜索关键词。修改现有正文无需再改前端文案。
- 示例图来自内置微积分课件。更新按钮或流程后，同步核对对应正文与截图。
