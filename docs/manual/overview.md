# 总览与章节整理

「总览」集中展示课程阅读位置、章节整理结果和最近笔记，适合开始学习前浏览或复习时回顾。

## 继续阅读 <!-- continue -->

选择课程后进入「总览」，点击「继续阅读」，回到上次阅读的位置。需要添加或调整章节时，点击「管理资料」。

总览围绕课程组织；独立课件可先加入课程，再使用章节整理。

## 整理章节 <!-- summarize -->

1. 确认相关章节已加入课程，并勾选为问答来源。
2. 选择「当前章节」「所选章节」或「全部问答来源」。选择所选章节时，在下方勾选目标。
3. 在整理设置中确认模型、思考强度和已有结果的处理方式。
4. 点击「整理本章」「整理所选章节」或「整理全部」。

![总览中的整理范围、设置和章节列表。](/manual/overview.jpg)

整理会调用模型。首次先根据课程目录和各章开头建立「课程初步框架」，再分批阅读每页文字和图像。每章在独立的持续会话中顺序阅读，完成后自动更新课程成果。预览不计入已读页数，结果中的引用可以回到原页。

在章节中点击「查看阅读记录」，可以查看各批次、章节成果和课程更新；点击「基于本章提问」，会新建继承该章已读内容的对话。新对话和独立解释窗优先继承当前章节，没有可用章节结果时使用课程总览。界面会显示继承来源与已读范围；不同连接间使用「继承上下文」。已有对话的起点不会随总览更新而改变。

## 暂停与继续 <!-- resume -->

整理过程中可以点击「暂停整理」，已完成的内容会保留。稍后点击「继续整理」；如果部分页面失败，点击「重试未完成内容」。

进度显示正在阅读的页范围，区分已读、失败、未读和复用页面。恢复时先核对模型端结果，跳过已完成批次。遇到错误时先查看提示，确认模型连接和资料状态，再继续。旧版结果继续保留，恢复旧版任务时会建立新的连续阅读版本。

## 汇总与更新 <!-- refresh -->

每完成一章都会更新课程成果，也可以点击「汇总已整理章节」重新梳理它们的共同主题和联系。

课程来源或章节结果发生变化时，旧汇总可能需要更新。已有结果默认可以复用；需要采用新设置重新处理时，在整理设置中选择「重新分析」。

历史结果用于比较和回看，不代表当前所有章节都已经整理。复杂的跨章比较、核查或练习生成，可以使用[研究与成果](#/manual/research)。

## 思维导图 <!-- mind-map -->

打开顶部「导图」，选择「整个课程」或「当前课件」。同一范围可以保存多份导图；可从空白创建，也可在生成设置中选择模型、填写生成重点后，点击「AI 生成初稿」。整课导图使用课程中全部课件，与问答来源勾选独立。

AI 优先复用完整的章节整理结果，否则读取课件的文字索引。长资料会分批汇总，可能产生多次模型调用。没有文字索引的扫描课件，应先在「总览」使用图像模型完成章节整理。生成过程中可停止；生成失败或发生版本冲突时，原导图不会被替换。AI 的组织与引用仍需结合原页核对。

点击节点后可在右侧编辑标题、备注、颜色、来源页码和网页链接。双击节点直接改名；支持增加子节点、增加同级、复制分支、删除分支、调整父节点、分支排序和左右方向。拖动分支会携带其后代，切换到自由布局；「自动排版」恢复双向树。中心主题不可删除或复制为第二个根节点。

画布支持拖动平移、滚轮缩放、适合画布、折叠展开、节点搜索和大纲视图。编辑器中使用 Ctrl+Z / Ctrl+Y 撤销重做、Ctrl+S 保存、Ctrl+F 搜索；选中节点后 F2 改名、Insert 新建子节点、Enter 新建同级，画布中的 Tab 新建子节点。输入法选词时不会触发编辑快捷键。

修改自动保存到本机数据库，未保存的本机草稿会在重新打开时恢复。出现「保存失败」时先导出 JSON 保留内容；并发更新不会强制覆盖另一窗口的版本。JSON 用于继续编辑和导入，SVG / PNG 用于图片分享，Markdown 保留全部节点与备注。图片导出当前展开的节点，JSON 和 Markdown 包含折叠内容。每份导图最多 300 个节点；当前不支持多人实时协作、XMind 原生文件、图片节点和跨分支关系线。
