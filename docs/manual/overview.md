# 总览与章节整理

「总览」集中展示课程阅读位置、章节整理结果和最近笔记，适合开始学习前浏览或复习时回顾。

## 继续阅读 <!-- continue -->

选择课程后进入「总览」，点击「继续阅读」，回到上次阅读的位置。需要添加或调整章节时，点击「管理资料」。

总览围绕课程组织；独立课件可先加入课程，再使用章节整理。

## 整理章节 <!-- summarize -->

1. 确认相关章节已加入课程，并勾选为问答来源。
2. 选择「当前章节」「所选章节」或「全部问答来源」。选择所选章节时，在下方勾选目标。
3. 在整理设置中确认模型、思考强度和已有结果的处理方式。
4. 点击「整理本章」「整理所选章节」或「整理全部」。

![总览中的整理范围、设置和章节列表。](/manual/overview.jpg)

整理会调用模型。可以先从当前章节开始，完成后再决定是否扩大范围。结果中的引用可以回到原页。

## 暂停与继续 <!-- resume -->

整理过程中可以点击「暂停整理」，已完成的内容会保留。稍后点击「继续整理」；如果部分页面失败，点击「重试未完成内容」。

进度会区分成功、失败和复用的页面。遇到错误时先查看提示，确认模型连接和资料状态，再继续。

## 汇总与更新 <!-- refresh -->

完成部分章节后，可以点击「汇总已整理章节」，查看它们的共同主题和联系。

课程来源或章节结果发生变化时，旧汇总可能需要更新。已有结果默认可以复用；需要采用新设置重新处理时，在整理设置中选择「重新分析」。

历史结果用于比较和回看，不代表当前所有章节都已经整理。复杂的跨章比较、核查或练习生成，可以使用[研究与成果](#/manual/research)。
