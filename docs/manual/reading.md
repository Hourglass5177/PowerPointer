# 阅读与定位

阅读区用于翻页、查找和选取原文。先定位内容，再决定是提问、框选还是记录笔记。

## 认识阅读界面 <!-- layout -->

左侧显示课程、课件和页面导航；中间是原文；右侧在「对话」与「笔记」之间切换。顶部切换「阅读」「总览」「资料」「历史」「研究」。

![阅读界面的导航、原文和侧栏。](/manual/reading.jpg)

可以收起左侧导航、关闭右侧面板，或拖动分隔线调整空间。展开对话后，长回答会获得更宽的阅读区域。窄屏使用「原文」「对话」「笔记」切换。

## 翻页与缩放 <!-- zoom -->

底部页码栏可以直接输入页码；箭头用于前后翻页。滚轮先滚动当前页，到达页边后再继续翻页。

使用底部缩放控件，或在课件上按住 Ctrl 滚动鼠标。「适合页面」显示完整页面，「适合宽度」适合阅读较小的文字。

## 搜索原文 <!-- search -->

点击顶部「搜索」，输入术语或关键词。选择结果可跳到对应页；需要把其他页的图表一起交给模型时，可以在结果中勾选「附图」，最多两页。

搜索依赖课件中可提取的文字。扫描图片里的文字可能搜不到，此时可以翻到目标页后框选。

## 选择文字或图表 <!-- selection -->

「选字」适合复制文字、引用到对话或记笔记；「框选」适合公式、图表和扫描页。

1. 点击「选字」后，沿文字拖动。
2. 需要图像时切换为「框选」，拖出目标区域。
3. 在选区菜单中选择解释、引用或记笔记。

![框选图表后，在选区菜单中选择后续操作。](/manual/selection.jpg)

框选尽量包含完整公式、坐标轴或题目条件。只截局部符号可能让模型缺少判断依据。

## 使用快捷键 <!-- shortcuts -->

| 按键 | 操作 |
| --- | --- |
| V / B | 选字 / 框选 |
| Ctrl + F | 搜索课件 |
| G | 输入页码 |
| ← / →、Page Up / Page Down | 上一页 / 下一页 |
| ↑ / ↓ | 页内滚动 |
| Home / End | 当前页顶部 / 底部 |
| Ctrl + Home / End | 第一页 / 最后一页 |
| + / − | 放大 / 缩小 |
| 0 / Shift + 0 | 适合页面 / 适合宽度 |
| ? | 快捷键帮助 |
| Esc | 取消当前操作或关闭最上层界面 |

翻页键需要焦点在阅读区；输入文字时不会触发阅读操作。「帮助 → 快捷键」可以查看说明并关闭单键快捷键。
