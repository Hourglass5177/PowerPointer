# 快速上手

从打开课件到保存笔记，走完常用的学习流程。没有准备资料时，可以先用内置微积分示例。

## 打开课件 <!-- open -->

启动 Power Pointer，在欢迎页选择「打开课件」，导入 PDF、PPT 或 PPTX。也可以拖入文件，或点击「体验示例」。

PDF 可以直接阅读。PPT 和 PPTX 需要本机安装 PowerPoint 或 LibreOffice，转换后显示静态页面。只有 PDF 时无需安装转换软件。

阅读、搜索和自己记笔记无需连接模型。需要 AI 解释时，再到[连接与设置](#/manual/settings/connect)完成连接。

## 找到要读的内容 <!-- read -->

左侧切换课件和页面，中间阅读原文，右侧查看对话或笔记。底部可以输入页码、调整缩放。窄窗口下，使用「原文」「对话」「笔记」切换面板。

![阅读界面：左侧课件与页面，中间原文，右侧对话与笔记。](/manual/reading.jpg)

拖选文字后会出现操作菜单。遇到公式、图表或扫描页，点击顶部「框选」，再拖出需要查看的区域。

## 解释难点，或先记下来 <!-- understand -->

- 想快速弄懂选区：选择「弹窗解释」，在解释窗里继续追问。
- 想自己记录：选择「记笔记」，直接写下理解。
- 想结合上下文讨论：将选区引用到对话，补充问题后发送。

没有选区也能在右侧直接提问，例如：“这页的结论成立需要哪些条件？”发送前检查资料范围和模型。

AI 回答可能有误。涉及公式、条件或结论时，点击来源回到原页核对。

## 保存有用的内容 <!-- save -->

回答下方的「存为笔记」会将内容保存到右侧「笔记」。也可以在那里点击「新笔记」，自行记录。

编辑笔记后会自动保存，离开前查看保存状态。笔记中的来源可以带你回到对应页；有选区时，也会定位原来的文字或图表。

## 下次接着读 <!-- continue -->

应用会记录阅读位置。课程的「总览」提供「继续阅读」；过去的对话在「历史」中查找；自己的记录在「笔记」中查找。
