# 课件与课程

临时阅读可以直接打开课件。需要跨章节学习时，将相关课件放进课程，统一管理顺序和问答来源。

## 导入文件 <!-- import -->

通过「打开课件」、左侧添加入口或拖放导入 PDF、PPT、PPTX。导入进度和错误可在「导入记录」中查看。

PPT 转换需要 PowerPoint 或 LibreOffice。转换结果保留静态页面，不播放动画、视频或音频。若版式有差异，可先用 PowerPoint 导出 PDF，再导入。

文件保存在应用的数据目录中，硬盘原文件不会因阅读、批注或整理而改变。当前单次导入的文件大小上限为 100 MB。

## 创建课程 <!-- course -->

1. 在课程选择处新建课程，填写名称。
2. 进入「资料」，通过「从资料库加入课件」加入已导入的文件，或连接课程文件夹。
3. 在「课程章节」中点击「打开」，开始阅读。

课程中的章节共享课程对话。切换到「独立课件」后，使用的是该课件的独立会话。

## 连接课程文件夹 <!-- folder -->

欢迎页的「连接课程文件夹」，或「资料」中的目录绑定入口，可以关联本机文件夹。

绑定后，在「硬盘目录」中勾选需要的文件，再确认同步。目录变化会列出新增、修改或删除的文件，由你确认后处理。

硬盘文件被删除时，应用内已有版本会保留；刷新目录不会直接删除原来的学习记录。同步前确认勾选范围，避免把无关文件加入课程。

## 调整章节与分组 <!-- organize -->

章节旁的更多操作可以修改「章节显示名」、分配「主题」或「上移章节」。显示名只改变应用内名称。

在「主题分组」中添加主题，再回到章节的更多操作分配。移除分组会保留章节。

## 选择问答来源 <!-- sources -->

「课程章节」旁的复选框决定哪些课件参与后续课程问答与整理。取消勾选后，课件仍可阅读。

「批量操作」可统一设置当前列表的问答来源。发送问题前，还可以选择当前页、附近页或更广的检索范围，详见[选择问答范围](#/manual/questions/scope)。

来源调整只影响后续请求，已经发送的问题保留当时的资料与选区。

## 移除与清理 <!-- remove -->

- **从课程移除**：章节退出当前课程，应用内课件仍然保留，可以再次加入。
- **最近移除**：课件退出最近列表，仍保留在资料库中。点击「撤销最近移除」，或从资料库重新打开即可恢复显示。
- **彻底删除**：清理应用内数据前会显示影响范围，可以选择是否同时删除该课件的正式会话和解释窗。确认后不能恢复，硬盘原文件保留。

保留的旧问答可能显示「来源已删除」。这些文字记录仍可阅读，但无法跳转到已删除的课件。
