# Power Pointer

Windows 本地课件阅读助手。直接打开 PDF、PPT、PPTX，提供独立的阅读、总览、资料、历史和研究工作区，以及就地点读、递归解释窗和跨课件引用。

日常操作可从应用顶部「帮助 → 使用手册」查阅，欢迎页与阅读引导也提供入口。手册支持离线搜索、章节直达和图片放大；教程源文见 [使用手册](docs/manual/README.md)。

## 启动与第一次提问

1. 双击本目录的 **`启动.cmd`**。启动器显示检查和准备进度，按源码及依赖指纹决定是否安装依赖或重新构建，再打开 <http://127.0.0.1:4317>。无变化时复用构建，构建失败会停止。保持启动窗口运行，Ctrl+C 可结束本应用。
2. 空资料库可选择“打开课件”“连接课程文件夹”或“体验示例”，也可拖入 PDF、PPT、PPTX。示例重复打开不会重复导入。引导可以跳过，并从顶部“帮助”重新打开；已有资料直接恢复原工作区。
3. 翻到要问的页，输入“这一步为什么成立”，按 **Enter** 或发送按钮；**Shift+Enter** 换行，Ctrl+Enter 也可发送。中文输入法选词时 Enter 不发送。
4. 选字或框选后显示“弹窗解释／记笔记／对话引用”。选取本身不调用 AI；对话引用在发送时才调用 AI。文字、右侧回答和解释窗回答均可右键“弹窗解释”，继续深入。

依赖：Windows、Node.js 24+；使用 Codex 订阅时需要官方 Codex CLI。PPT 导入还需本机安装 Microsoft PowerPoint 或 LibreOffice，两者均已在当前机器检测并验证。软件不会自动安装 Office 或调用在线转换网站。手动启动：

```powershell
Set-Location -LiteralPath 'E:\大学\AI课件阅读器'
npm ci
npm run build
npm start
```

端口占用时可在 PowerShell 设置 `$env:PORT='4319'` 再启动。本服务仅监听 `127.0.0.1`。

## AI 连接与模型

“设置”打开 AI 连接中心，可管理 Codex 订阅、OpenAI Responses、Anthropic Messages、Gemini，以及兼容 OpenAI 的 DeepSeek、通义千问、OpenRouter、Ollama、LM Studio 和自定义服务。服务地址填写 API 根路径；先获取模型或填写模型 ID，再按服务实际能力确认图像、工具调用和推理支持。

- Codex 自动检测本机 CLI 与已有 ChatGPT 登录，也可在连接设置填写可执行路径。登录和刷新由官方 CLI 处理；额度只显示 App Server 实际返回的数据。订阅连接不会使用 API Key，也不会自动转向其他收费服务。
- API 密钥仅在后端通过 Windows 当前用户 DPAPI 加密后存入本地数据库，不回传明文，不放进浏览器存储或导出文件。本地模型服务可以不填密钥。切换服务是用户的明确选择，应用不会自动备用切换。
- 问答输入区直接选择助手、模型和资料范围。模型支持搜索、收藏、最近使用和显示名；“快速／深入／批量”可保存自己的模型、助手、思考强度和工具参数。
- 仅文本模型可以处理文字任务。图像能力未知时不会自动假定支持，需确认能力或选择“仅文本”；扫描页和图表应使用图像模型。推理参数只填写服务实际支持的值：Anthropic 的常规强度使用 adaptive 模式，旧模型固定预算可填 budget:4096；Gemini 强度使用 thinkingLevel，固定预算可填 budget:4096。
- 同一可见对话切换模型后携带本地历史与来源，并标明切换。不同服务的远端线程相互独立；分支只复制目标之前的记录。旧会话默认迁移为 Codex，迁移前保存 before-ai-v4.sqlite。
- 内置课程讲解、推导核查、跨资料研究和复习出题助手，可修改方法、风格、默认模型、范围及工具权限，也可新建助手。学习偏好、术语和目标只在主动保存后进入学习背景，可编辑或删除。
- 用量页按连接、模型和任务记录耗时及实际 Token；服务未返回时显示“未提供”。没有可靠单价时不估算费用。

## 研究与成果

从顶部“研究”或选区菜单提出目标，选择来源和模型，任务会读取资料、查找笔记、核对证据并保存报告、对照表、提纲或练习题。步骤记录对应真实调用与结果；本地资料与外部网页均作为证据，不改变任务或工具授权。

- 任务可在后台继续，也可停止、阶段暂停和继续。全应用最多两个模型任务并发；每次最多 15 分钟，原生 API 最多 20 次模型请求。Codex 按请求及可见工具操作计入 20 轮上限，不声称能统计 CLI 内部不可见的推理次数。重启后的未完成任务标为结果未确认，不自动重发。
- 报告和笔记修改保留版本；成果支持 Markdown 编辑、预览、版本恢复、回收站及导出。版本冲突保留草稿，可载入最新版本或另存副本。写入按任务和内容去重，继续执行不会重复创建同一成果。
- 双模型对比使用同一份初始资料和选区，独立生成；桌面双栏、窄屏标签切换。可采用任一回答继续正式对话，也可从已有回答发起另一模型核查。意见一致不代表事实已证实。
- 开启联网后，Codex 可使用内置搜索；其他服务通过“工具扩展”中明确配置的 Brave Search 搜索，也可读取公开网页。网页读取阻止本机及私有网络地址。
- 自定义 HTTP MCP 需用户添加服务、获取工具、启用声明为只读的工具，并逐助手授权。调用前重新核对工具定义与当前授权；不开放任意终端、脚本或外部写入。
- 每个研究任务显示冻结的资料、笔记、讨论和学习背景。较长历史使用摘录，原始记录仍保留。

协议参考：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[OpenAI Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)、[Claude 思考与工具调用](https://platform.claude.com/docs/en/about-claude/models/extended-thinking-models)、[Gemini 思考配置](https://ai.google.dev/gemini-api/docs/generate-content/thinking)。当前以个人本地使用为目标；未实现商业托管登录。

## 界面与 PPT 导入

- 顶部保留“阅读／总览／资料／历史／研究”。左栏课程菜单提供切换与新建；课件列表按主题显示章节名称、阅读位置和整理状态，也可切换页面缩略图。
- 阅读工具为选字、框选、搜索、适配、更多；旋转与全屏收在“更多”。工作区切换保留当前页、缩放、会话、草稿和解释窗。
- 页码和缩放集中在底栏。新课件默认显示完整一页；桌面新默认左栏 230px、右栏 390px，已有宽度偏好保留。右栏可拖动、收起或切换对话／笔记；“展开解释”在宽屏隐藏导航并扩展至 600px，退出后恢复。900–1199px 默认收起导航，小于 900px 使用原文／对话／笔记单面板切换。
- 阅读区使用方向键、PageUp/PageDown 翻页；输入框内保留正常编辑按键。Esc 关闭菜单或返回并排问答，解释窗需点自己的关闭按钮，Enter / Ctrl+Enter 发送问题。
- PPT/PPTX 优先由 PowerPoint 生成静态 PDF 缓存，找不到 PowerPoint 时使用 LibreOffice；PowerPoint 失败后可点“使用兼容引擎重试”。兼容引擎可能出现字体、行距或排版差异。
- 导入记录显示处理状态，支持取消和重试。取消后不会提交文档；PowerPoint 当前调用返回后关闭本次导入副本。超时为 180 秒，允许最多 15 秒结束辅助进程；不会按进程名强制关闭用户的 PowerPoint。
- 缓存保留隐藏幻灯片，序号与原课件一致。原文稿只读打开，宏禁用；不保存对原文稿的更改。当前 Office 构建会忽略导出隐藏页参数，因此只在导入副本的内存中展开隐藏页，再导出并关闭。
- PPT 的动画、视频、逐步出现效果不播放，不提供幻灯片编辑。受保护、加密或损坏的文件会明确报错。导入重启中断后需要手动重试。

## 点读、课程与清理

- 解释窗可以拖动、缩放、最小化，不自动收起旧窗。选中窗内术语再右键可创建子窗；关闭父窗保留子窗，“关闭这一支”才关闭后代。刷新或重启恢复未关闭窗口、草稿和已收到内容，生成中断后不会自动重发。窄屏通过底部解释窗标签切换。
- 每个窗口冻结创建时的课程来源、已完成侧栏讨论和父链背景；优先携带最近及相关讨论，更早的内容可按需检索。它不会读到之后的侧栏讨论或兄弟窗。窗口设置中可独立调整模型、强度、联网，也可“保存为正式对话”。
- “总览”直接显示章节目录、继续阅读位置与最近笔记。“整理本章”只处理当前课件，也可选择若干章或全部问答来源。任务读完一章就保存该章摘要，再继续下一章；支持暂停、恢复和仅重试失败页。单章不自动生成课程长文，可另点“汇总已整理章节”；全部整理结束后汇总一次。成功页、失败页和实际覆盖范围分别显示，导入不自动调用 AI。
- 同课程同时执行一个整理任务；重复启动复用当前任务，切换范围或模型须先暂停。缓存按文件内容、有效模型、强度和提示词版本区分，可选择重新分析。旧摘要与历史版本继续可读；来源变化显示过期提示，不自动重新分析。问题及解释窗冻结当时使用的摘要、来源和笔记，后续更新不会改写已冻结背景。
- “资料”顶部提供添加文件、连接目录、搜索和批量问答来源设置。每份课件是一章，可修改显示名、顺序和主题分组，原文件名保留。新目录资料自然排序，已有章节相对顺序保留。目录及子目录变更经过监听、启动检查、每分钟核对或手动刷新发现，确认后才同步；内容变化导入新版本，旧问答仍对应旧版。
- 右侧“笔记”默认显示本章，可查看全课程并搜索。支持手写、文字／框选摘录、正式回答及任意层级解释窗回答收藏；重复收藏返回原笔记。标题和 Markdown 正文可编辑，提供公式、代码预览及 500ms 自动保存。保存失败保留本地草稿，版本冲突可重新载入或另存；删除可撤销与恢复。
- 笔记固定来源、页码、摘录和选区坐标，页面显示轻量标记，点击来源可跳页并高亮跨行文字。框选图片单独保存；删除来源或关闭解释窗后，笔记及已有截图仍保留。独立课件也支持笔记；同一课件在不同课程中的笔记和继续阅读位置互相独立。后续问题只使用当前来源范围内的笔记，并标注为用户参考，原文仍作为证据。
- “资料 → 全部资料”的“最近移除”可撤销；“彻底删除”清理应用副本、索引和知识来源，保留硬盘原文件，默认保留旧问答并标记来源已删除。可另勾选删除以该课件为主的会话和解释窗。跨课件会话中的引用也会标记。
- “历史”默认显示当前课程，可搜索、按课程或课件筛选，查看和导出包括已删除来源在内的历史；支持继续、归档、恢复和删除。附件按引用关系清理，只删除登记属于本应用的模型线程。清理失败可重试。
- 临时窗使用 ephemeral 模型线程，本地内容与正式历史分开保存；关闭后清理独占内容。所有解释窗共用一条事件流，最多同时执行两个模型任务，前台优先于后台建库。

## 阅读、范围与记录

- 顶部提供“阅读／总览／资料／历史／研究”切换；左栏用于课程、课件列表和页面导航。问答空态提供“概括本页／解释概念／逐步解答／联系前文”图标卡片，点击填入草稿，发送后才调用模型。
- **Ctrl＋滚轮**围绕鼠标所在位置缩放课件，范围 10%–400%；仅在课件区域接管，不缩放整个浏览器。
- 滚轮先滚动当前页，到顶部或底部后停一下再滚动即可翻页；整页已显示时直接翻页。同一次连续手势最多翻一页，触控板惯性不会连翻。右侧对话和缩略图独立滚动。“更多阅读操作”可关闭滚轮翻页。
- 快捷键：**V** 选字、**B** 框选、**Ctrl/Cmd+F** 搜索、**G** 输入页码、**+ / −** 缩放、**0** 适合页面、**Shift+0** 适合宽度。课件区域内 **← / →、Page Up / Page Down** 翻页，**↑ / ↓** 页内滚动，**Home / End** 到页边，**Ctrl/Cmd+Home / End** 到首尾页。
- **?** 或“更多 → 快捷键帮助”查看全部按键，也可关闭单键快捷键。输入文字、使用中文输入法、操作菜单和弹窗时不触发阅读快捷键。页码输入按 Enter 跳转，Esc 放弃；其他位置 Esc 每次只取消当前操作或关闭最上层临时界面。
- 发送时冻结文档、会话、物理页码、旋转、选区及 AI 设置。随后翻页或换课件不会改变这条问题的归属；追问会保留原回答的页面与选区。
- **当前页**：本页图像、文字与选区。**附近页**：再加入前后各两页文字。**全文检索**：SQLite FTS5、中文分词/汉字二元词与 BM25，在本次选定课程来源中补充相关文字片段。新增背景文字预算为 12,000 字符，当前页优先。
- 搜索结果可以勾选最多两页“附图”。整页/裁图默认按最长边约 2,100 像素渲染，最大 3 倍 PDF 原始尺寸。问题下方“已发送材料”可查看实际截图与文字；回答下方“来源”只显示回答中有效引用的材料。引用悬停或键盘聚焦显示缩略图与来源上下文，点击跳页。
- 这些范围仅控制本轮新增资料，不隔离已保留的会话历史。引用点击按 PDF 物理页码或 PPT 原幻灯片序号跳转；无法对应有效来源的链接不会变成可点击引用。
- 单份课件或课程独立保存会话；同一课程切换章节会保留当前正式对话；“+”创建新会话，历史按钮可搜索标题及消息、重命名、置顶、归档或恢复。草稿按课件与会话保存在当前浏览器，刷新后恢复；生成期间可继续写下一条问题。
- 问答窗格可展开为宽阅读区。流式回答跟随底部；向上阅读时不会强行滚回，可点“回到最新”。支持 Markdown、公式、表格、代码块，以及复制问题、回答和代码。
- “修改问题”和“重新回答”会新建分支，同时切分模型记忆，保留目标问题之前的历史，原会话保持不变。修改使用原问题的页面和选区，可更换模型等设置。重新回答采用输入框的当前 AI 设置；错误重试沿用原设置和资料。未知结果先核对，不自动重复生成。缺少可靠的远端切分位置时明确报错。
- 回答下方的追问和“再简单些”等操作只填入草稿，发送后才调用模型。回答长度与思考强度分别设置。线程恢复失败会显示错误，断线不自动重发。
- 问答窗格顶部“…”中的导出命令输出 Markdown，包含课件名、页码、选择文字、裁图坐标和引用说明；首版 Markdown 导出不打包截图文件。

## 数据与权限

`data/library.sqlite` 保存资料索引、阅读位置、会话、问答、笔记和导入任务；`data/originals` 保存原始副本，`data/pdfs` 保存阅读缓存，`data/attachments` 保存已发送页面、裁图和框选笔记图片。旧版全文索引迁移前备份为 `data/before-power-pointer-v2.sqlite`，本次笔记与章节迁移前备份为 `data/before-learning-v3.sqlite`；旧记录无需重建，也不会自动重跑 AI。未关闭的解释窗及冻结背景保存在数据库中，原文件不修改。可用 `LECTURE_DATA_DIR` 设置本地数据目录。

Codex 的令牌与线程继续保存在其托管目录（本机 `F:\Tools\OpenAI\CodexHome`；由 `CODEX_HOME` 或本地路径配置决定）。完整迁移会话需要保留该托管状态，单独备份应用数据库并不能保证模型线程可恢复。停机后备份 `data`；不要把它或本机路径配置提交到 Git。

输入框中的“设置”可分别设置以下只读能力，下一次提问生效：

- **课件工具**默认开启：模型可检索本次选定的课件、查看课程目录、读取页面文字和真实图像；单课件遵循当前页/附近页/整份课件范围及显式附图，课程请求在冻结的来源清单内查阅。每次最多读取两页图像，单轮最多调用 16 次。不允许传入任意路径或访问未选定的课件。解释窗另可检索创建时冻结的历史背景。
- **网络搜索与网页阅读**默认关闭：开启后模型可搜索公开网页、打开页面和页内查找，回答使用直接来源链接。工具调用过程可展开查看。搜索关键词会发送给服务；页面及网页内容均作为资料处理。

终端、文件写入、其他连接器、插件和钩子禁用，未知工具或审批请求拒绝。为兼容当前模型，工具通过 Codex 隔离的 V8 调度器执行；它仅调度已配置的读取工具，不提供系统终端或文件 API。本轮设置通过专用 App Server 进程生效；继承的其他 MCP 服务显式禁用，不改动用户全局配置。应用 HTTP 接口校验主机、来源和会话，不开放任意路径或任意 App Server RPC。普通翻页、阅读选字、对话引用、本地检索、历史浏览和连接状态检查不启动推理。选择“弹窗解释”、右键询问、发送问题和主动建库会调用模型。
